<section class="project-entry">
  <p class="project-meta">IoT / Simulation / Smart Farming</p>
  <h2>Distributed simulation for sustainable smart farming</h2>
  <p>Designed a simulation framework for sensor deployment and data processing in smart farming, including line-of-sight deployment, UAV relays, mobility models, energy models, and fog-backed computation.</p>

<section class="project-entry">
  <p class="project-meta">Fog Federation / Resource Management</p>
  <h2>xFogSim resource management framework</h2>
  <p>Developed a lightweight framework for locality-aware fog resource allocation, addressing latency, network delay, packet error rate, availability, cost, and performance trade-offs for IoT services.</p>
  <div class="project-tags"><span>Edge computing</span><span>Optimization</span><span>IoT services</span></div>
</section>

<section class="project-entry">
  <p class="project-meta">Smart Cities / Edge Computing</p>
  <h2>Sustainable vehicle-assisted data migration</h2>
  <p>Proposed a vehicle-assisted migration framework that uses neural-network-based selection of data carriers to reduce backend network use, improve transfer efficiency, and lower emissions.</p>
  <div class="project-tags"><span>Smart cities</span><span>Neural networks</span><span>Sustainable computing</span></div>
</section>

<section class="project-entry">
  <p class="project-meta">Computer Vision / Visual Attention</p>
  <h2>Three-pathway spatiotemporal visual saliency model</h2>
  <p>Developed a saliency model combining static features, dynamic motion, face detection, and center bias to predict eye movements during free video viewing.</p>
  <div class="project-tags"><span>Saliency</span><span>Eye tracking</span><span>Video analysis</span></div>
</section>
